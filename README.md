# SmartServe Backend

A Java-based backend system designed to manage banking operations with secure database integration, transaction handling, and modular CRUD functionality.

## Features

- Account creation and management
- Deposit and withdrawal operations
- Transaction handling
- MySQL database integration
- JDBC connectivity
- Exception handling
- Modular backend structure

## Tech Stack

- Java
- JDBC
- MySQL
- IntelliJ IDEA
